# ppwcode Angular SDK

The ppwcode Angular SDK is an SDK built on top of Angular, to speed up project development. Its libraries are pushed to npmjs.org, allowing their consumers to use them for common practices within the applications we develop. This repository holds the libraries, Storybook for the documentation and a demo application further showcasing the usage of the libraries.

## What makes this SDK special?

The libraries focus on making the project code more readable by hiding code that could be considered boilerplate or copied across projects. It focuses on reusability and standardization of implementation, allowing the necessary flexibility to extend or modify its inner workings.

## Small glossary

We need to be on the same page with terminology. When communicating, use this language:

* **you** means the agent reading this file and changing code.
* **we, us, and maintainers** mean the people building the SDK. These are who you are talking to now.

## How you should behave

Ideas can be ambitious but need to be proven. Keep things simple so that it feels obvious. Do not introduce new concepts or ideas because it looks architecturally impressive. Understand the real constraint and then fight for the smallest readable and architecturally sound solution.

Fight scope creep, try to honor the developer's intent.
