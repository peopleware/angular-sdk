# Security

Our version support policy is described in [PRACTICES.md](PRACTICES.md).

Report suspected vulnerabilities in the `@ppwcode` Angular SDK packages privately to the maintainers through
[GitHub private vulnerability reporting](https://github.com/peopleware/angular-sdk/security/advisories/new?report=vulnerability).
Do not publish vulnerability details in a public issue or pull request.

Include the affected package and version, reproduction steps or a minimal proof of concept, and the potential impact.
Do not include credentials or personal data.

For vulnerabilities in Angular itself, follow [Angular's security policy](https://github.com/angular/angular/blob/main/SECURITY.md).
